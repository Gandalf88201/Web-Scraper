How to Find CSS Selectors

  1. Open the target website in Chrome or Firefox
  2. Right-click on an exhibitor card and select "Inspect"
  3. The DevTools will open showing the HTML
  4. Find the element's class or ID attribute
  5. Use it as a selector (e.g., .exhibitor-card for class, #main for ID)

Examples:

  • Class: <div class="exhibitor-card"> → .exhibitor-card
  • ID: <div id="content"> → #content
  • Tag + Class: <img class="logo"> → img.logo
  • Nested: .card .title finds title inside card
